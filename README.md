# 📺 StreamHive

StreamHive is een moderne webapplicatie waar gebruikers video’s kunnen uploaden, bekijken en interactie hebben met content van anderen. Het platform is ontworpen om het delen van video’s eenvoudig en sociaal te maken.

## 🚀 Features

- 📤 Video’s uploaden  
- 🗑️ Video’s verwijderen  
- ❤️ Video’s liken  
- 💬 Reageren op video’s  
- 👀 Video’s bekijken  

## 🛠️ Technologieën

- Frontend: HTML, CSS, JavaScript
- Backend: PHP 
- Database: MySQL
